# 💍 Indian Weddings Cost Analysis

## 📌 Project Overview
This project performs **Exploratory Data Analysis (EDA)** on an Indian Weddings Cost dataset using **Python**. The analysis focuses on understanding wedding expenses across different wedding types, locations, decoration categories, entertainment, invitation cards, and gift categories. Various data cleaning techniques, statistical analysis, visualizations, pivot tables, and an interactive dashboard are used to extract meaningful insights.

---

## 🎯 Objectives
- Clean and preprocess the dataset.
- Handle missing values and incorrect data.
- Explore categorical and numerical features.
- Perform statistical analysis.
- Create insightful visualizations.
- Analyze average costs using GroupBy and Pivot Tables.
- Build an interactive dashboard.
